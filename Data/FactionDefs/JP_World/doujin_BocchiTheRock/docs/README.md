# Bocchi the Rock!: Character Research Index

Research date: 2026-10-30. Scope: the original manga by Aki Hamazi (latest ~volume 8, chapter 73+) and the 13-episode TV anime (2022, CloverWorks). Each character file contains **two state sets**: the situation as of the end of the TV anime, and the situation as of the latest manga. Performance/composer trivia and real-world musician name derivations are included only where they inform the characters. Spin-off manga (*Kikuri Hiroi's Heavy-Drinking Diary*) material is marked when used.

Series titles: EN *Bocchi the Rock!* / JP ぼっち・ざ・ろっく！ / CN 孤独摇滚！（Bilibili official) / TW 孤獨搖滔！(uncertain rendering, unverified).

Band: Kessoku Band (結束バンド). Official Simplified Chinese rendering of the band name was **not verified** in fetched sources; files therefore use EN/JP only for the band name. Do not invent a CN rendering.
